# DBFL · Connect the Future

A number-path puzzle for Graduate Fair 2026. Connect the numbered checkpoints in order and use every square without crossing the path.

## Play

Open index.html through a static web server. Warm-up (5×5), Challenge (6×6) and Expert (7×7) puzzles include touch drawing, tap controls, keyboard navigation, undo, hints, a timer and local personal bests.

## Deploy on Vercel

Import this repository. Choose **Other** as the framework preset, leave the build command empty and use the repository root as the output directory. No environment variables or packages are required.

## Notes

Best times stay on the player's device. Hinted completions do not set personal bests. This version has no shared leaderboard or competition entry form.

Both game assets and the grid sizing fix are included.
